DCC CV Vault

Your decoder settings, kept.

Every DCC modeller has done it: spent an evening getting a locomotive running exactly right, then months later changed one CV and lost the setup you can no longer remember.

Get it on the App Store What it does

iPhone, iPad, and Mac. One locomotive free — a single lifetime purchase unlocks an unlimited roster.

A notebook for your decoders

Keep a real record

CV numbers, values, and your own notes for every locomotive. Indexed CVs are supported.

Snapshot before you tune

Save the current state under a name you will recognise, compare it against what you have now, and put it back if the new values are worse.

CV 29 without the arithmetic

Set direction, speed steps, and address length with switches. The app works out the value and leaves the reserved bits alone.

Function mapping you'll still understand next year

Record what F0 through F28 actually do on each locomotive, with notes.

Import what you already have

Bring in locomotives from a JMRI roster. Every import is previewed before anything is added, and you choose how conflicts are resolved.

Your data stays yours

Export one locomotive or your whole roster as plain JSON you keep. No account, no analytics, no advertising, no server.

An unknown CV is not a CV set to zero. A value you have not read yet stays marked unknown and is shown differently, because guessing it is worse than admitting you do not know it.

What it does not do

  • It does not read from or program decoders. It records what you set them to.
  • It does not connect to a command station or your layout.
  • It has no account, no analytics, no advertising, and no server.
